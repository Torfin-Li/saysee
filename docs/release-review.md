# 公开源码最终审查

日期：2026-10-29。范围：Saysee 0.1.0 公开预览源码。用户已明确授权本次审查通过后创建并推送个人公开仓库 `Torfin-Li/saysee`，采用 MIT 许可证；不包含正式 DMG 或 GitHub Release 发行。

## 结论

独立只读复查未发现阻碍源码公开的安全或正确性问题。真实云端整理仍待用户完成 macOS 钥匙串授权；当前不把这项流程描述为端到端验收通过。

## 已修正

- 界面明确告知完整转录会发送到 DeepSeek，音频只在本地内存处理。
- App 从空目录打包，显式复制资源，防止旧文件混入；收集嵌套依赖许可及 NOTICE。
- 发行构建映射源码路径、移除调试信息，使用受限的匿名临时缓存路径，避免个人主目录路径进入产物。
- 已删除另一个云服务的认证、环境读取、设置、测试及 CLI 路径，只保留 DeepSeek；升级清理旧 App 配置，不访问或删除外部凭证文件。
- 钥匙串读写移出主线程；服务页延迟读取，读写期间保护密钥操作，取消的旧读取不能解除新读取的 loading。
- 保存空密钥时检查删除结果，系统拒绝删除会报告错误，不伪装为保存成功。

## 验证依据

- 当前 33 项 Swift 测试、7 项发布边界 Python 测试通过，脚本语法及公开文档链接检查通过。已从仅含公开文件的快照验证 Swift 测试不依赖本地实验、模型或真实凭证。
- 既有 Release App 完成 ad-hoc 签名与严格验证，在禁止联网的沙盒中验证中文、英文、静音、取消后结果拒绝和新会话。原生设置窗口可打开并响应，动效由同一 SwiftUI 绘制代码生成预览检查；不代替真人麦克风验收。
- 精确暂存快照与 App 文本资源使用 gitleaks 8.30.1 扫描。公开内容不含模型权重、实验、内部记录、设计截图、真实配置、日志、录音、密钥或证书；最终脱敏报告和逐文件清单保留在忽略的 dist/public-audit/。
- 约 2 GB 模型 tensor 不作文本秘密扫描，已核对其 SHA-256 与固定上游 revision 的 LFS metadata 一致。

```text
model revision: edd077a475c4da058e25b6e6ec1199115ca1be2b
model.safetensors sha256: cacb094fef227ec2a5908d0136b3ad3384d95e0e2a8a915984ce577e4b12b2ba
```

扫描未发现秘密不等于能够证明不存在一切未知泄露形态。源码提交前重新审计暂存区，首次 push 前扫描完整提交历史；使用 GitHub noreply 邮箱，避免误公开工作或私人邮箱。

## 已知限制与后续发行

- 同步 GPU 生成不能 token 级抢占，取消立即作废结果，但当前块可能继续计算。
- 自动输入采用保守 AX 目标检查，部分编辑器回退到剪贴板；派发粘贴不等于目标确认插入。
- LLM 仍可能误纠词、误概括或推断关系，重要文本需人工核对。
- 实际 DeepSeek 请求尚待系统钥匙串授权后验收；物理快捷键、权限变化、跨应用输入和长口述仍需持续真人验证。
- 远端 CI 在首次 push 后检查。Developer ID、Apple 公证、DMG 和干净系统安装尚未完成；当前只公开预览源码，不宣称正式安装包可分发。

后续正式发行要求见 releasing.md。本次公开不得上传本地 App、模型或私有配置作为未经审阅的附件。
