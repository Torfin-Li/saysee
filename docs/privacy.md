# 隐私与数据流

## 发往何处

麦克风 → 本地内存 PCM → 本地 Qwen 转录 → DeepSeek 文本 API → 本地结果及系统剪贴板／目标输入框。

完整转录会发送到云端进行纠错和提炼，而不是只发送本地已经整理好的文字。音频不发送给这些文本接口，应用不主动将原始音频写入磁盘。云服务的数据保留、区域和计费由用户选择的提供方及账号配置决定，Saysee 不替服务商作数据处理承诺。

## 凭证与配置

- DeepSeek API Key 使用 macOS Keychain 保存。掩码显示不改变底层存储；用户主动显示或复制后，相应数据可出现在界面或剪贴板中。
- 仅保留 DeepSeek。应用不读取本地云服务账号文件、其路径或云认证环境变量；升级时删除旧的服务路径、项目、区域和服务选择设置，不读取或删除外部文件。
- 普通模型配置保存在系统 UserDefaults，API Key 使用 Keychain，处理正文保留在内存。应用没有产品内转录历史数据库。

## 本地日志与剪贴板

诊断日志位于 `~/Library/Logs/Saysee/saysee.jsonl`，包含会话标识、阶段、耗时、长度计数、模型配置和必要错误类别。不会记录转录／成稿正文、私钥、完整服务响应或 API Key。文件超过 5 MB 后轮换一次。

输出通常会留在系统剪贴板，复制密钥也会写入剪贴板；这些内容可能被操作系统的剪贴板功能或其他有相应访问能力的软件读取。用户可自行覆盖或清空剪贴板。

显式开发命令 `--transcribe`、`--check-stt` 和 `--check-stt-paced` 会将指定文件的转录打印到 stdout，仅应用于用户主动选择的测试数据；这与默认诊断日志不打印正文不同。设置页的“测试连接”只发送固定合成文本，但会产生 DeepSeek API 请求和费用。

## 系统权限

麦克风权限用于收音；输入监控用于全局快捷键；辅助功能用于检查焦点和派发一次粘贴。普通键盘输入不保存到日志。安全输入和可识别密码框不会自动填入。辅助功能信息不完整时采用复制及结果卡片回退，不遍历整个文档寻找猜测的输入位置。

公开问题报告应使用合成文本、脱敏日志和遮挡凭证后的截图，避免包含私有语音、客户数据、私人路径或编辑器内容。
